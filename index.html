What is BuildJava.ln?

BuildJava.ln is a learning repository where I practice Java by building small programs. Each exercise focuses on programming concepts and keeps the Java source code together with a study guide.

The goal is to understand how the language works by writing, reviewing, and improving code — not just collecting finished tutorials.

How the project works

  1. Choose a practical programming exercise.
  2. Write a Java program to solve it.
  3. Study the concepts and document what the code does.

The current collection has ten exercises, from beginner fundamentals to intermediate object-oriented programming and collections.
