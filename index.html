Learning Java in public

Java makes more sense one small program at a time.

BuildJava.ln is a public learning log of Java exercises. Follow a concept-led route from console input and decisions to collections, then open any project to see what it practices. The stages are an orientation, not a prerequisite checklist or a claim that every exercise is finished.

01 Suggested learning path

From first values to useful collections.

Read the stages as a concept-led route through the exercises—not as prerequisites. Each stop explains what the listed project practices and how it connects to the next set of ideas.

This is a provisional editorial ordering based on the checked-in guides and code, not a strict prerequisite sequence. Stage labels are presentation order, not assigned roadmapOrder values; only JoKenPo currently has an explicit value (6). The active source-backed projects do not introduce an if/else and counted-loop foundation before LoginIntermediary and JoKenPo. Git history contains older versions of DrivingCarWallet and ReturnName, removed as obsolete in commit 73b0689. Their historical code suggests a bridge after TypeProfile: DrivingCarWallet introduces token-to-line input and an if/else decision, then ReturnName adds a counted loop. They are not active projects in this checkout, so that historical bridge does not close the current learning-path gap.

    04 About the project

    A learning log, built in the open.

    BuildJava.ln is a collection of Java practice projects and notes. Project descriptions explain the task; outcomes and concepts describe what each exercise is intended to practice. Source availability is identified separately where it could not be verified. The catalog marks projects as in-progress, so this site does not claim that they are finished.
