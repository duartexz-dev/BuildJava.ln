01 / THE PROJECT

Small programs.
Concrete concepts.

The goal is to turn each topic into something that can be run, inspected, and improved. The exercises begin with console input and control flow, then move into classes, objects, constructors, and collections.

Every exercise has two connected parts: a Markdown guide that explains the learning goal, and the Java file that contains the implementation.
